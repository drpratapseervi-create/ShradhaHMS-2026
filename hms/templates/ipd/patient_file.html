What do these do?

Load template prefills the fields below from a standard procedure template — review and edit before saving.

Load from patient record fills empty Diagnosis, Chief Complaints, General Examination, Investigations (Hb/TLC/Platelet/RBS/HIV/HBsAg/USG), Procedure Performed, IPD Treatment and Course in Hospital from what's already recorded on this IPD file (Diagnosis, Symptoms, Vitals, Investigations, Medication, Progress Notes & Treatment tabs), plus default template text for Condition at Discharge and Discharge Advice. General Examination is built from the latest vitals reading; IPD Treatment is built from the inpatient Medication Chart; Course in Hospital is built from Progress Notes (SOAP), left blank if none were recorded. Never overwrites text you've already entered — review and edit before saving. Runs automatically when this tab is opened.
